## Reflection

### 1. Git Commit History

If I were hiring someone and saw this history, it would show me that they work in an organized way and make changes one step at a time. Each commit has a clear description, making it easier to understand what was changed and why.

### 2. How Git Changes My Approach

Using Git helps me keep track of changes I make to my Python scripts instead of worrying about losing previous versions. Before this module, I would simply save my files, but now I can make smaller changes, commit them individually, and go back to earlier versions if necessary.

### 3. Additional .gitignore Entry

I would add `*~` to my `.gitignore` file because some Linux text editors create temporary backup files ending with a tilde. Since I use a Chromebook with Linux, I would not want these unnecessary backup files uploaded to my GitHub repository.
